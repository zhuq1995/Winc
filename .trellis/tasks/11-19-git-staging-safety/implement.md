# 实施计划

1. 检查工作区和 Git 暂存规范。复现回滚前后的索引、工作区和 HEAD 变化。
2. 修复回滚基准、候选范围、确认和在途写入保护。增加暂存新增、删除、改名后的回滚及范围回归。
3. 修复右键、键盘的组身份和暂存方向。整文件暂存接入保存路径，覆盖未保存内容和保存失败。
4. 恢复空索引提交的确认和真实索引判断。测试首提交、忽略文件、取消、提交失败、非空索引及推送／同步续接。
5. 运行目标用例、cargo test -p winc-editor、cargo test -p winc-app、cargo test -p winc-i18n、cargo fmt --all --check 和 cargo clippy --workspace --all-targets -- -D warnings。
6. 独立核对用户入口、Git 实际内容和已有功能。更新 Git 暂存规范与 fork 保留清单。提交时按明确路径整理当前任务文件。

回滚、入口和提交按独立变更范围检查。测试使用临时仓库。用户现有工作区的其他改动沿用当前归属。
